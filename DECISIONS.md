## Технические решения

| Дата | Решение | Обоснование |
|------|---------|-------------|
| 2026-03-26 | Статический HTML/CSS/JS без фреймворков | Нет build-шага, работает на GitHub Pages из коробки |
| 2026-03-26 | GitHub Pages + Cloudflare CDN | Бесплатный хостинг + глобальное CDN + SSL |

| 2026-10-01 | css/style.css → css/stylevZen.css → css/style-v3.css: каскад импортов, каждый слой переопределяет только нужные CSS-переменные | Позволяет держать несколько визуальных тем (старая, vZen-концепт, v3-продакшн) без дублирования базовых компонентов (nav, карточки, формы, футер) |
| 2026-10-01 | css/style-v3.css и js/v3.js стали основными стилем/скриптом продакшн-сайта (index.html, about.html и т.д., EN+ES) | Дизайн v3 одобрен пользователем и перенесён с прототипа index-v3.html на весь сайт |

## Технические заметки

- Старый дизайн (тёмно-синий/оранжевый, без vZen-слоя) не удалён физически — он доступен в истории git (коммиты до 2026-10-01) и может быть восстановлен при необходимости.
- Экспериментальные файлы *vZen.html (indexvZen.html, aboutvZen.html, ... , pricingvZen.html) и css/stylevZen.css остаются как отдельная, не основная ветка с исходной (фиолетово-синей) палитрой Zenox — их никто не трогал при переносе v3 в продакшн.
- pricingvZen.html (иллюстративные примеры цен) сознательно НЕ добавлена в навигацию основного сайта — пользователь подтвердил это явно 2026-10-01.
